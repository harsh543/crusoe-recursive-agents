# Hackathon tracks (as given)

Pick one and build an agent team on Crusoe Managed Inference.

## Done Means Done
Agents fill in vague goals with their own assumptions, then confidently report success. Build a team that writes its own definition of done, checks its work with tests or independent verifier agents, catches itself drifting or looping, and decides whether to continue, re-plan, stop or (rarely) ping a human.
**Question:** how can agents turn a one-line goal into checks they can run without you, so you can walk away?

## Shared Brain
Every new agent on a team starts from zero and pays again for the same context. Build a shared memory layer: a living project every agent reads before it works and updates afterward.
**Question:** how can a team keep shared knowledge current, lean and conflict-free while showing measurable gains in output quality?

## Version N+1
Most agent teams are exactly as good on run 100 as on run 1. Build a team that, after each run, reviews what worked and what didn't, rewrites its own prompts, playbooks, tools or team structure, and keeps a change only if it measurably helps.
**Question:** how can a team turn its own history into a better version of itself, and prove it with a before-and-after score on tasks it hasn't seen?

## Common requirement
Every track asks for something measurable (verifier pass rate, quality gain with memory, held-out before/after score). Whatever we pick, build the eval first.

## Not published (ask organizers)
Judging criteria, prize split, submission process and deadline, rules on pre-existing code, hackathon credits.
